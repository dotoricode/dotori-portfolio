# 자기소개

## 안녕하세요, Dotori입니다

사용자 경험을 중심으로 생각하는 풀스택 개발자입니다. 복잡한 문제를 단순하게 해결하고, 의미 있는 가치를 만드는 것을 즐깁니다.

## 핵심 역량

- **프론트엔드**: React, TypeScript를 활용한 반응형 웹 애플리케이션 개발
- **백엔드**: Node.js, Express를 이용한 RESTful API 설계 및 구현
- **DevOps**: Docker, GitHub Actions를 통한 CI/CD 파이프라인 구축
- **데이터베이스**: PostgreSQL 설계 및 쿼리 최적화

## 관심 분야

- 웹 성능 최적화 및 사용자 경험 개선
- 오픈소스 프로젝트 기여
- 클린 코드와 테스트 주도 개발(TDD)
- 신규 기술 스택 탐구 및 적용

## 교육

- 컴퓨터공학 학사 졸업
- 관련 온라인 강의 및 자격증 취득 다수
