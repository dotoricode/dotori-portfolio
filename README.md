# dotori portfolio

Public profile hub for dotori and acorn-labs.

## Focus

- Building a one-person AI company around Hermes Desktop as an operating office
- Turning useful AI workflows into small products, templates, and repeatable systems
- Keeping public projects practical, verifiable, and founder-friendly

- [hermes-desktop](https://github.com/dotoricode/hermes-desktop): adapting Hermes Desktop into an AI office for acorn
- [korean-humanizer](https://github.com/dotoricode/korean-humanizer): Korean writing humanizer for more natural public copy
- [prompt-grill](https://github.com/dotoricode/prompt-grill): prompt testing and comparison workflow
- [dotClaude](https://github.com/dotoricode/dotClaude): AI agent workflow and Claude Code environment notes
- [tuz-landing](https://github.com/dotoricode/tuz-landing): landing page and product experiment

## Principles

- Make AI work visible through logs, tests, docs, and repeatable checklists
- Prefer small, shippable systems over vague automation
- Convert repeated work into skills, cron jobs, or documented workflows
